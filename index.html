About Pathfinder

Pathfinder is an interactive grid where you can watch classic search algorithms explore space step by step, cell by cell, until they find — or fail to find — a route from a start point to a target.

How to use it

  1. Start mode — click a cell to place the green start node.
  2. Target mode — click a cell to place the coral target node.
  3. Wall mode — click or click-and-drag to paint obstacles the search cannot pass through.
  4. Erase mode — click or drag to remove walls.
  5. Pick an algorithm and a speed, then press Visualize.
  6. Clear Walls removes obstacles only. Reset Board clears everything, including start/target.
  7. Random Walls scatters obstacles across the grid instantly.

Reading the animation

  • Cyan pulse — a cell the algorithm has examined.
  • Amber glow — the final path once the target is reached.
  • Dark cell — an obstacle; no algorithm can cross it.

The algorithms

Breadth-First Search (BFS) explores the grid in expanding rings, one step at a time. On an unweighted grid like this one, it always finds the shortest path, but it checks many cells it doesn't strictly need to.

Depth-First Search (DFS) commits to a direction and follows it as far as possible before backtracking. It is fast to code and easy to reason about, but the path it finds is rarely the shortest one.

Dijkstra's Algorithm always expands the closest unvisited cell first. On this grid, where every step costs the same, it behaves like BFS — but the same logic scales to grids with variable movement costs.

A* Search is Dijkstra plus a heuristic: it estimates the remaining distance to the target (using Manhattan distance here) and prioritizes cells that look promising. It typically reaches the target while examining far fewer cells than the others.

Why this matters

These are the same core ideas behind route planning in maps, NPC movement in games, and the informed-search techniques (Greedy Best-First, A*, Hill Climbing) covered in most introductory AI courses. Watching them run side by side on the same grid makes their trade-offs — speed, memory, and optimality — visible instead of abstract.
