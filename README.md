## 🎯 Features

| | |
|---|---|
| 🟢 🔴 | Place **start** and **target** nodes anywhere on the grid |
| 🧱 | Draw or erase **walls** by clicking and dragging |
| 🧠 | Switch between **4 search algorithms** on the fly |
| 🎚️ | **Adjustable animation speed** — from instant to cinematic |
| 🎲 | **Random wall generator** for quick maze challenges |
| 📊 | **Live stats** — cells visited, path length, run time |
| 📖 | Built-in **info panel** explaining how each algorithm works |

### 🔍 Algorithms included

<div align="center">

| Algorithm | Guarantees Shortest Path? | Strategy |
|:---:|:---:|:---|
| **BFS** — Breadth-First Search | ✅ | Explores layer by layer |
| **DFS** — Depth-First Search | ❌ | Dives deep before backtracking |
| **Dijkstra's Algorithm** | ✅ | Explores by cumulative cost |
| **A\* Search** | ✅ | Cost + heuristic — smart & fast |

</div>

## 🚀 How to Use

```
1️⃣  Select a mode  → Start / Target / Wall / Erase
2️⃣  Click the grid → Place start point, target point, and walls
3️⃣  Pick your algorithm and animation speed
4️⃣  Hit "Visualize" and watch it search!
5️⃣  Use "Clear Walls" or "Reset Board" to try again
```

---

## 💡 Why This Project?

> Built to make the search algorithms taught in introductory AI coursework — **BFS, DFS, Dijkstra, A\*** — *visible* instead of abstract. Watching cells light up as they're explored makes the trade-offs between **speed**, **memory**, and **path optimality** click in a way pseudocode never quite manages.
